OpenAPI.

## Get a product

<ApiEndpoint method="GET" path="/api/products/{id}">Returns one product</ApiEndpoint>

| Parameter | In   | Type     | Description     |
| --------- | ---- | -------- | --------------- |
| `id`      | path | `string` | The product id. |

```json title="Response 200"
{
  "id": "42",
  "name": { "en": "Coffee mug", "sv": "Kaffekopp" },
  "price": 129
}
```
